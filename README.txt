Maria & Hassan - Invitation website

Files (keep them together in the same folder):
- index.html       Main invitation page
- intro.mp4        Opening video (shown first)
- intro-poster.jpg First frame of the opening video, shown before tapping Play
- cover.png        Maria & Hassan swans image shown after the opening video ends
- background.png   Fixed lace-and-flowers background behind the invitation sections
- music.mp3        Add your chosen background music file here (not included yet)

Opening sequence:
1. The intro video poster appears first (not cover.png).
2. Tap “افتح الدعوة” to play intro.mp4 and start music.mp3.
3. When the video ends, cover.png appears, followed by the invitation sections.

Publish the folder to GitHub Pages or another web host. The music file must be named exactly music.mp3.
